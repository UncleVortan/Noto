# Changelog

All notable changes to Noto are documented here.

Format: [Semantic Versioning](https://semver.org) — `MAJOR.MINOR.PATCH`

---

## [1.0.0] — 2026

### Added
- Notes editor with autosave, search, and file import
- AI flashcard generation (5, 10, or 15 cards per set)
- AI quiz generation with multiple-choice questions
- AI Chat with optional note context
- Focus Timer with Pomodoro, Short, and Deep Work modes
- Dashboard with stats overview and weekly activity
- Stats page with quiz history and focus tracking
- Multi-provider AI support: Groq, OpenAI, Anthropic, Cohere
- Export all data as JSON, Markdown, CSV, or plain text
- Import data from a Noto JSON backup
- Fully client-side — no server, no account, no tracking
