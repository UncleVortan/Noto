# Noto Roadmap

This is a living document. Items move as the project evolves.

---

## ✅ v1.0 — Current

- [x] Notes with autosave, search, file import
- [x] AI flashcard generation from notes
- [x] AI quiz generation from notes and flashcard sets
- [x] AI Chat with note context
- [x] Pomodoro / Focus Timer
- [x] Dashboard with stats
- [x] Multi-provider AI (Groq, OpenAI, Anthropic, Cohere)
- [x] Export data (JSON, CSV, Markdown, TXT)
- [x] Import data backup
- [x] Fully offline except AI calls
- [x] No account or server required

---

## 🔜 v1.1 — Quality of Life

- [ ] Markdown rendering in the note editor
- [ ] Keyboard shortcuts (Ctrl+N new note, Ctrl+S save, etc.)
- [ ] Light / dark theme toggle
- [ ] Note tagging and tag filtering
- [ ] Better mobile layout (bottom nav bar on small screens)
- [ ] Drag-and-drop note reordering
- [ ] Word and character count in status bar

---

## 🔜 v1.2 — Flashcards & Study

- [ ] Spaced repetition algorithm (SM-2) for card review
- [ ] "Study mode" — automatic card progression with confidence rating
- [ ] Anki export (`.apkg` format)
- [ ] Card editing after generation
- [ ] Import flashcards from CSV

---

## 🔜 v1.3 — AI & Documents

- [ ] Ollama support (run AI locally, fully offline)
- [ ] Mistral AI support
- [ ] PDF text extraction (via PDF.js)
- [ ] AI-powered note linking ("this looks similar to another note")
- [ ] Ask questions about multiple notes at once

---

## 🔜 v1.4 — Collaboration & Sync

- [ ] Optional Firebase sync (free tier)
- [ ] Share a note via link (read-only)
- [ ] Export to Notion / Obsidian format

---

## 💡 Ideas Under Consideration

- Browser extension that sends page content directly to Noto
- PWA / installable app support
- Voice notes (Web Speech API)
- Image support in notes
- Mind map view for notes

---

## Won't Do (by design)

- Accounts / cloud storage by default — privacy first
- Ads or monetisation
- Tracking or analytics
- Dependencies / npm packages
- Build step requirement

---

Want to pick up something from this list? Open an issue and let us know!
